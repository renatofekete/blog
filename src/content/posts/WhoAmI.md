7+ years writing frontend code. I never wrote about it. That changes now.

## Background

I'm Renato, a web developer, working mostly on frontend codebases. I'm from Beli Manastir, a small town in Croatia, so all my development experience has been remote, be it as a freelancer, or a part of different sized teams.

I've spent the last few years building websites and apps for clients, and I'm currently looking for my next role while working on a few projects in public.

This blog exists for two reasons. First, I want to document what I'm actually building. Second, writing is a way for me to learn things on a deeper level - if I can't explain it, I don't know it well enough.

## What I'll write about

- Building in public - I'm currently learning Next.js and building a link shortener from scratch. I'll document the process as I go.
- Small JavaScript tools and open source experiments.
- Web development deep dives.
